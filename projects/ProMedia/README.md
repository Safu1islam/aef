# ProMedia

**→ [github.com/Safu1islam/ProMedia](https://github.com/Safu1islam/ProMedia)**

A single-operator social media production and publishing system — media
ingest, a rights-clearing gate, scheduling, and publishing — built end to end
under AEF starting 2026-08-08. It's the operator's own active project, not a
demo written to showcase the framework; AEF is the process it happens to be
built with.

It used to be mirrored into this repository as a full source snapshot; it now
lives in its own repository with its real commit history, and this page is
just the pointer. Its `.ai/state/` there carries the same kind of history the
framework asks every project to keep — a project constitution, decision
records, a task plan, and session/lock state written continuously by the
agents that worked on it — so it's worth reading directly at the source
rather than a copy here that would drift.
